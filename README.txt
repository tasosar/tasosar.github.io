2. Upload the complete folder to a web host, keeping the folder structure intact.
3. Add the final canonical domain URL and generate sitemap.xml using that exact domain.
4. Verify the domain in Google Search Console and submit the sitemap; request indexing for the Greek and English pages.
5. Add the exact LinkedIn and Facebook profile URLs when available.
